# Phase 32.4 — Staff, Assignments, Access Ladder & Settings Fix

This phase fixes the reported usability issues in Staff & Assignments, Access Ladder and Settings.

### Staff
- Add staff
- Edit staff
- Established labour roles:
  Construction Manager, Foreman, Charge Hand, Electrician, 4th Year, 3rd Year, 2nd Year, 1st Year, GO
- Existing staff are preserved.
- Standard staff can be restored without deleting custom staff.

### Assignments
- Assign a staff member to DUB10/DUB50 or another accessible project.
- Edit assignment role, start/finish dates, status and notes.
- Assignment data persists and remains the source for project manpower/resource views.

### Access Ladder
Nine defined levels are seeded and repaired automatically:
1. Viewer
2. Site User
3. Foreman / Charge Hand
4. Site Manager
5. Project Manager
6. Construction Manager
7. Business Unit Lead
8. Company Director
9. Company Administrator

### Settings
Company Administrators now have a Settings tab with persistent:
- Accent colour
- Sidebar colour
- Page background
- Card colour
- Text colour
- Display density
- Default dashboard

See `PHASE32_4_QA.md` for exact validation results.
