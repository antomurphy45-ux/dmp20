# Phase 32.5 — Settings Theme Fix

This phase fixes the Settings customisation problem where the application stayed blue after changing colours.

### Settings now control
- Accent / primary UI colour
- Sidebar colour
- Page background
- Card colour
- Main text colour
- Display density
- Default dashboard

Colour changes preview immediately and are persisted when **Save customisation** is pressed. The saved values are restored on the next login.

The existing DUB10/DUB50 data and Phase 32.4 staff/assignment/access-ladder functionality are retained.

See `PHASE32_5_QA.md` for exact validation results.


### Phase 32.7 visual correction
Company customisation is intentionally limited to the sidebar and header. Operational/status colours remain fixed and meaningful.
