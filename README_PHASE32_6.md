# Phase 32.6 — Professional Theme Rollback

Phase 32.6 corrects the Phase 32.5 theme behaviour. Settings customisation remains available for the application shell, but the established dashboard/status colour palette is no longer replaced by the selected accent colour.

## Behaviour
- Accent colour can customise primary buttons.
- Sidebar colour can customise the navigation shell.
- Page background, card background, text colour and density remain customisable.
- Dashboard/status colours retain their established meanings: blue, green, amber, red, purple and teal.
- Project health indicators are not recoloured by the accent setting.
- Root and static CSS/JS remain synchronised.

See `PHASE32_6_QA.md` for validation.
